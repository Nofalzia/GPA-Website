# GPA Calculator | Bahria University

**Live demo:** [https://my-grade.netlify.app/](https://my-grade.netlify.app/)

## What it does
A specialized GPA and CGPA calculator meticulously tailored to the grading policies of Bahria University (BUIC). It provides students with an intuitive interface to calculate semester GPAs, track cumulative progress, and receive strategic academic advice through an integrated "Improvement Plan."

## Tech stack
- **Core:** HTML5, CSS3, Vanilla JavaScript
- **Storage:** LocalStorage API for client-side data persistence
- **Typography & Icons:** Google Fonts (Inter), Font Awesome
- **SEO & Metadata:** Schema.org JSON-LD, Open Graph meta tags

## Key features
- **University-Specific Calculation:** Automatically applies Bahria University's 4.0 scale grading policy (A, A-, B+, etc.).
- **Multi-Semester CGPA Tool:** Weighted CGPA calculation based on credit hours across multiple semesters.
- **Smart Persistence:** Automatically saves your input data to your browser, so your grades are still there when you return.
- **Improvement Strategy:** Built-in guidance for different student tiers (High Achievers, Low Scoring, or Underperforming) with actionable advice.
- **Marks-to-Grade Reference:** A quick-access conversion table to translate raw exam marks into their respective letter grades.

## Getting started
1. Clone the repository to your local machine.
2. Navigate to the project folder.
3. Open `index.html` directly in any modern web browser (Chrome, Firefox, Edge, etc.).
*No installation or build steps are required.*

## Why I built this
I noticed a lack of GPA calculators that actually adhered to Bahria University's specific grading nuances, and most existing tools lacked a premium visual experience; I built this to bridge that gap with a tool that is both functionally accurate and aesthetically pleasing.
